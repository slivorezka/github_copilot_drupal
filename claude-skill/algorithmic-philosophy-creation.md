# Algorithmic Philosophy Creation

## 1. Skill Overview
- **Domain**: Philosophical reasoning and framework construction
- **Key Goal**: Apply systematic, algorithmic methods to create rigorous, coherent philosophical arguments, theories, and frameworks.

## 2. Core Methodology
- **Approach**: Structured, step-by-step philosophical reasoning
- **Logic System**: Classical and modal logic, with support for dialectical and phenomenological methods
- **Output Standard**: Peer-review-ready philosophical arguments with full premise transparency

## 3. Philosophical Foundations & Style
- **Primary Standard**: Analytic philosophy clarity combined with continental depth
- **Argument Structure**:
  - Every claim **must** be traceable to explicit premises.
  - Use numbered premise-conclusion format for deductive arguments.
  - Distinguish between descriptive and normative claims.
- **Docblocks** (Argument Metadata):
  - All frameworks, arguments, and theses must include: `@premise`, `@conclusion`, `@counterargument`, `@domain`.

## 4. Framework Architecture
- **Thesis Layer**:
  - All philosophical work must begin with a clearly defined thesis.
  - Thesis must be falsifiable or at minimum contestable.
  - Use the Thesis-Antithesis-Synthesis (Hegelian) or Premise-Argument-Conclusion (Analytic) structure.
- **Argument Layer**:
  - Arguments should be decomposed into atomic units (single inferential steps).
  - Avoid informal fallacies; document logical form (modus ponens, modus tollens, etc.).
- **Synthesis Layer**:
  - Resolve tensions between competing positions.
  - Explicitly acknowledge the limits of the framework (scope conditions).
- **Meta-Philosophy**:
  - All frameworks must include a self-reflective section addressing their own epistemological assumptions.

## 5. Dialectical Development
- **Thesis Construction**:
  - Define the domain and scope.
  - State initial assumptions and axioms.
- **Antithesis Generation**:
  - Systematically generate the strongest possible counterarguments (steelman approach).
  - Classify counterarguments by type: empirical, logical, normative, pragmatic.
- **Synthesis**:
  - Identify common ground.
  - Produce a higher-order position that preserves valid insights from both thesis and antithesis.

## 6. Testing & Validation
- **Logical Consistency**: Use formal logic checks (no contradictions in premises).
- **Thought Experiments**: Test framework against canonical edge cases (trolley problem, Chinese Room, etc.).
- **Counterexample Analysis**: Attempt to falsify each claim with a concrete counterexample.
- **Coverage**: Aim to address at least three major objections for any philosophical position.

## 7. Ethical & Epistemic Responsibility
- **Bias Acknowledgment**: Identify cultural, historical, and linguistic biases embedded in the framework.
- **Uncertainty**: Clearly mark claims by epistemic status: known, probable, speculative.
- **Permissions**: Distinguish between descriptive claims (what is) and normative claims (what ought to be).
